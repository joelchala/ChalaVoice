ChalaVoice v1.1.0

Suite Chala · Manifest V3 · 100% Local & Offline

ChalaVoice es una extensión de navegador Manifest V3 de código abierto para lectura en voz alta 100% local, sin servidores externos, sin telemetría y con cero dependencias externas.

Capacidades principales

  • Popup compacto + Mini Barra Flotante persistente: la síntesis se ejecuta dentro de la pestaña activa (o en reader/index.html para libros) para no interrumpirse al cerrar el Popup, acompañada de una mini barra arrastrable aislada en Shadow DOM.
  • Modo Inspector ("Seleccionar párrafo inicial"): apunta a cualquier párrafo, encabezado o lista con recuadro naranja y haz clic para leer desde ese punto exacto (Esc para cancelar).
  • Motor Anti-Congelamiento de 3 capas: subdivisión inteligente de oraciones (≤200 caracteres), pausas naturales diferenciadas y Watchdog automático ante bloqueos de síntesis en Chromium.
  • Perfiles acústicos y Sleep Timer: detección local de idioma, ranking de voces Natural/Neural/Online/Google/Apple, 4 presets y temporizador con atenuación gradual.
  • Lector de Libros offline: soporte nativo de .epub (PKZIP + DecompressionStream('deflate-raw')), .md, .txt y texto pegado con guardado de progreso en chrome.storage.local.

Compatibilidad y Comandos (v1.1.0)

Compatible con Chrome >= 109, Edge >= 109 y Firefox >= 113. Requisitos de compilación: Node.js >= 22. Ejecuta npm run icons, npm run build y npm test.

ChalaVoice is an open-source Manifest V3 browser extension for 100% local text-to-speech reading with zero external servers, zero telemetry, and zero external dependencies.

Core Capabilities

  • Compact Popup + Persistent Floating Mini-Bar: speech synthesis runs persistently inside the active tab (or in reader/index.html for books) alongside a draggable Shadow DOM mini-bar.
  • Inspector Mode ("Select starting paragraph"): hover over any paragraph, heading, or list with an orange highlight frame and click to start reading aloud from that exact block (Esc to cancel).
  • 3-Layer Anti-Freeze Engine: smart chunking (≤200 chars), differentiated sentence/paragraph pauses, active utterance GC retention, and automatic Watchdog recovery.
  • Voice Ranking & Sleep Timer: local language detection prioritizing Natural/Neural/Online/Google/Apple voices, 4 one-click presets, and fade-out Sleep Timer.
  • Offline Book Reader: native parsing for .epub (PKZIP + DecompressionStream('deflate-raw')), .md, .txt, and pasted text with saved progress in chrome.storage.local.

Compatibility & Commands (v1.1.0)

Compatible with Chrome >= 109, Edge >= 109, and Firefox >= 113. Build requirements: Node.js >= 22. Run npm run icons, npm run build, and npm test.
