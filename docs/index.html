ChalaVoice v1.0.0

Suite Chala · Manifest V3 · 100% Local & Offline

ChalaVoice es una extensión de navegador Manifest V3 de código abierto para lectura en voz alta 100% local, sin servidores externos, sin telemetría y con cero dependencias externas.

Capacidades principales

  • Motor Anti-Congelamiento de 3 capas: subdivisión inteligente de párrafos y oraciones (≤200 caracteres), pausas naturales diferenciadas y Watchdog automático ante bloqueos de síntesis en Chromium.
  • Perfiles acústicos y ranking de voces: detección local de idioma y clasificación priorizada de voces Natural, Neural, Online, Google y Apple, más 4 presets (Narrador Rústico, Voz Suave, Modo Estudio, Natural) y Sleep Timer con atenuación gradual.
  • Modo Página Web: extracción heurística local (readability.js) con resaltado en vivo del párrafo y oración activa y clic para saltar.
  • Modo Libros y Textos: lector local de .epub (PKZIP + DecompressionStream('deflate-raw')), .md, .txt y texto pegado, guardando progreso exacto en chrome.storage.local.

Comandos de desarrollo

Requisitos: Node.js >= 22. Ejecuta npm run icons, npm run build y npm test.

ChalaVoice is an open-source Manifest V3 browser extension for 100% local text-to-speech reading with zero external servers, zero telemetry, and zero external dependencies.

Core Capabilities

  • 3-Layer Anti-Freeze Engine: smart paragraph/sentence chunking (≤200 chars), differentiated sentence/paragraph pauses, active utterance GC retention, and automatic Watchdog recovery.
  • Voice Ranking & Acoustic Presets: local language detection and voice ranking prioritizing Natural, Neural, Online, Google, and Apple voices, 4 one-click presets, and a fade-out Sleep Timer.
  • Web Page Mode: local heuristic extraction (readability.js) with live paragraph/sentence highlighting and click-to-jump navigation.
  • Books & Texts Mode: offline parser for .epub (native PKZIP + DecompressionStream('deflate-raw')), .md, .txt, and pasted text with saved reading progress in chrome.storage.local.

Development Commands

Requirements: Node.js >= 22. Run npm run icons, npm run build, and npm test.
