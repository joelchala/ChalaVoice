# Documentación Local de ChalaVoice (v1.1.0)

La documentación interactiva bilingüe (Español / English) se encuentra en [`docs/index.html`](index.html), incluyendo la guía de compatibilidad (`Chrome/Edge >= 109`, `Firefox >= 113`, `Node.js >= 22`) y novedades de la versión `1.1.0`.

Puedes abrir `docs/index.html` directamente en cualquier navegador sin necesidad de servidor web ni conexión a internet.
